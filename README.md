# G-Shock GA-V01 Drop Test Simulator

Interactive drop test simulator comparing the structural shock resistance and magnetic hand decoupling mechanism of the **Casio G-Shock GA-V01** against a luxury mechanical timepiece (Rolex Submariner homage) and a solid-state touchscreen smartwatch (Apple Watch).

## Features
- **4 Authentic GA-V01 Colorways**: Neon Lime (with orange hand), Stealth Matte Black (with white hands), Titanium Silver, and Cyber Purple (with cyan hands).
- **Physical Geometry**: Sculpted bezel with engraved `G-SHOCK` and `PROTECTION`, 4 corner bolt bosses, flank gear-teeth bumpers, and signature oval strap airflow vent hole.
- **Magnetic Decoupling Physics**: Minute hand slips on its magnetic clutch under high G-forces to prevent gear stripping, then snaps back to true time automatically.
- **Expressive Damage States**: Progressive damage states on the smartwatch (o_o alert, >_< wincing, x_x dead face with OLED glitch lines, X_X obliteration).
- **Direct Interactive Controls**: Drag the laser elevation line directly on the screen or use quick-preset chips (Desk 0.8m, Wrist 1.5m, Balcony 5m, Casio Triple-10 10m).
- **Audio Telemetry**: Built-in Web Audio API sound effects for freefall acceleration, rubberized impact thuds, metallic clinks, and glass shatters.
- **Responsive Layout**: Optimized for both desktop and mobile screens without awkward vertical scrolling.

## Run Locally
Simply open `index.html` or `ga-v01-drop-test.html` in any modern web browser. No external dependencies or build tools required.
